# 🎹 Piano Interactivo en Vue.js

Aplicación web interactiva desarrollada con Vue.js para simular un piano funcional.

> 💡 **Nota:** Este repositorio contiene la aplicación dentro de la carpeta `/piano`. Los siguientes comandos deben ejecutarse dentro de ese directorio.

## 🛠️ Tecnologías y Configuración

* **Framework:** Vue.js
* **Lenguaje:** JavaScript
* **Entorno:** Node.js

## 🚀 Cómo ejecutar este proyecto localmente

1.  **Clona el repositorio:**
    ```bash
    git clone [https://github.com/jahaziel17/ProyectosPersonalesFront.git](https://github.com/jahaziel17/ProyectosPersonalesFront.git)
    ```
2.  **Entra a la carpeta del proyecto:**
    ```bash
    cd ProyectosPersonalesFront/piano
    ```
3.  **Instala las dependencias:**
    ```bash
    npm install
    ```
4.  **Ejecuta el servidor de desarrollo:**
    ```bash
    npm run serve
    ```
5.  Abre un navegador en la dirección que te indique la terminal (usualmente `http://localhost:8080`).
